# Editorial rarity and sourced answer sets

We assign each accepted answer one editorial rarity tier and score it as a walk (10), single (50), double (100), or home run (200). Every prompt records its source and 2025-season cutoff, and the bank excludes Negro Leagues prompts unless the cited record set supports a complete answer list; Baseball-Reference is linked for reading only because its policy restricts building from scraped site data. The initial 28 daily decks cycle after day 28 so the standalone game can continue without a server.
