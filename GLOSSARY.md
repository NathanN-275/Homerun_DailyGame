# Baseball Daily Game

This context defines the shared terms used by the daily baseball trivia game.

## Language

**At-bat**:
One timed question in the seven-question daily game.
_Avoid_: Round, possession

**Answer tier**:
The editorial rarity label attached to a valid answer: Walk, Single, Double, or Home Run.
_Avoid_: Difficulty level

**Daily deck**:
The seven prompts assigned to one Eastern calendar date.
_Avoid_: Quiz set

**Cutoff**:
The latest season included when a prompt's answer list was established.
_Avoid_: Current season

**Complete answer set**:
Every answer that satisfies the wording and cutoff of one prompt, with accepted aliases recorded alongside it.
_Avoid_: Sample answers

**Personal best**:
The highest completed daily score saved in this browser.
_Avoid_: High score table
